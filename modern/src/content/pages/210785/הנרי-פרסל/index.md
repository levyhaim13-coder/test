<span style="font-family:arial,helvetica,sans-serif;"><span style="font-size:14px;"><strong><span style="color: rgb(255, 0, 0);"><u>הנרי פרסל</u>&nbsp;&nbsp;</span><span style="color:#ff0000;">Henry Purcell</span><span dir="RTL">&nbsp;</span></strong></span></span><strong><strong style="font-size: 14px;"><span style="color: rgb(255, 0, 0);"><span style="font-family:arial,helvetica,sans-serif;"><span style="font-size:14px;"><span dir="ltr">)&nbsp;</span>&nbsp;&nbsp;1659-1695 )</span></span></span></strong></strong><br>
<br>
<br>
<strong><span style="font-family:arial,helvetica,sans-serif;"><span style="font-size:14px;">הנרי פרסל, &nbsp;גדול <a href="http://he.wikipedia.org/wiki/%D7%9E%D7%9C%D7%97%D7%99%D7%9F" title="מלחין">המלחינים</a> ב<a href="http://he.wikipedia.org/wiki/%D7%90%D7%A0%D7%92%D7%9C%D7%99%D7%94" title="אנגליה">אנגליה</a>. פרסל הפנים את מוזיקת הבארוק ולמעשה הנו גדול הבארוק האנגלי.. פרסל למעשה שם את אנגליה על מפת המוזיקה במאה ה-17.. בימי חייו הקצרים חיבר פרסל יצירות רבות מאוד. המוזיקה שלו כללה אבל מול הכנעה שמחה מול עצב המפואר והבומבסטי מול העוני והמרוד המרגש הריקודי מול הפסטורלי כמו כן כתב פרסל <a href="http://he.wikipedia.org/wiki/%D7%A9%D7%99%D7%A8" title="שיר">שירי</a> תהילה וברכה לציון ארועים משמחים בחצר המלוכה. מכלול יצירותיו כוללות גם מוזיקה דתית חילונית.. בזמנו של פרסל המוזיקה הינה טונאלית ( מפסיקים לכתוב בשיטה המודאלית) המעבר הנו לשני סולמות בלבד מז'ור ומינור.. פרסל כתב את המוזיקה שלו על פי החוקים אשר היו קיימים באותה תקופה (מאמץ את תאוריית המוזיקה האיטלקית). ולמעשה ניתן לומר כי אנגליה לא תרמה דבר להתפתחותה של המוזיקה בתקופה זו. היחודיות של פרסל היא בהתאמת המוזיקה למחזות מוזיקליים (פרסל הרבה לכתוב <a href="http://he.wikipedia.org/wiki/%D7%9E%D7%95%D7%96%D7%99%D7%A7%D7%94" title="מוזיקה">מוזיקה</a> אינסידנטלית מוזיקה <a href="http://he.wikipedia.org/wiki/%D7%9E%D7%97%D7%96%D7%94" title="מחזה">למחזות</a> מוזיקליים &nbsp;כמו - <a href="http://he.wikipedia.org/wiki/%D7%94%D7%9E%D7%9C%D7%9A_%D7%90%D7%A8%D7%AA%D7%95%D7%A8" title="המלך ארתור">המלך ארתור</a>, מלכת הפיות, <a href="http://he.wikipedia.org/wiki/%D7%94%D7%A1%D7%A2%D7%A8%D7%94" title="הסערה">הסערה</a>, ו<a href="http://he.wikipedia.org/w/index.php?title=%D7%97%D7%9C%D7%95%D7%9D_%D7%9C%D7%99%D7%9C_%D7%A7%D7%99%D7%A5&amp;action=edit" title="חלום ליל קיץ">חלום ליל קיץ</a> (מאת <a href="http://he.wikipedia.org/wiki/%D7%A9%D7%99%D7%99%D7%A7%D7%A1%D7%A4%D7%99%D7%A8" title="שייקספיר">שייקספיר</a>).&nbsp;<br>
